# 帧像 · 摄影师作品集 App（Photographer Portfolio Android）

> 为摄影师打造的作品展示 App：按系列整理作品，全屏看图可双指缩放，
> 照片从手机相册导入，完全离线、零权限、无广告。

![帧像](icon.png)

## 特点

- **按系列分类**：人像、风光、街拍……每个系列一张封面、一个名字，首页一目了然
- **全屏看图**：双指缩放细节、双击快速放大、左右滑动切换，把作品完整呈现给观众
- **相册导入**：从手机相册多选照片一键加入，随时更新作品，不用电脑、不用联网
- **系列管理**：系列随时重命名，封面自选，作品集越用越顺手
- **干净与隐私**：零第三方依赖、无广告无追踪；照片只存在手机本地，卸载即彻底消失

## 安装

点击"下载 APK"把安装包保存到手机 → 打开安装包 → 允许"安装未知来源应用"→ 安装完成。
要求 Android 7.0（API 24）及以上；安装包约 57 KB。

备用直连（下载按钮不可用时）：

- [GitHub Release 直链](https://github.com/Trek-ai/photographer-portfolio-android/releases/latest/download/frameimage-release.apk)
- [Raw 直连](https://raw.githubusercontent.com/Trek-ai/photographer-portfolio-android/main/frameimage-release.apk)

## 技术说明

- 纯 Android 原生 Java 实现，零第三方依赖
- 无需任何权限：不申请存储、网络、定位
- 完全离线：无账号、无云同步、无数据上报
- 图片复制进 App 私有目录，删除 App 即彻底清除
